## Панель Remnawave [#req-panel]

* Версия **2.7.4 или новее**, ветка 3.x тоже подходит. Мастер установки проверит версию сам.
* **API-токен.** В панели: Settings → API Tokens → Create. Проще всего выбрать все права.

Без этих прав мастер дальше не пустит:

| Право | Зачем |
| --- | --- |
| `system:metadata` | версия панели |
| `users:list` | список пользователей |
| `users:by-short-uuid` | найти пользователя по ссылке подписки |
| `internal-squads:list` | сквады |

<Callout>
На отдельном сервере вместе с прослойкой поднимается страница подписки Remnawave, и она ходит в панель тем же токеном. Поэтому токену нужны ещё `subscriptions:subpage-config`, `subscription-page-configs:list` и `subscription-page-configs:get`. На панелях 2.7.x у токенов нет отдельных прав, подходит любой токен.
</Callout>

Остальные права нужны отдельным функциям. Без них прослойка работает, просто часть кнопок в админке будет неактивна. Полный список мастер покажет на шаге «Панель».

## Домен и HTTPS [#req-domain]

* **Домен.** Зависит от режима. Вместо текущей подписки — домен подписки панели (`SUB_PUBLIC_DOMAIN`). Для зеркала — новый домен: домен подписки панели для зеркала не подходит, с него зеркало берёт подписки. DNS-запись домена должна указывать на сервер прослойки.
* **Сертификат.** HTTPS настраивает реверс-прокси: ваш nginx, Caddy, панель хостинга, либо Caddy или nginx из готового `docker-compose.yml`, которые выпускают сертификат сами.
* **Только по домену.** По IP-адресу прослойка не открывает ни мастер, ни подписку.
* **Заголовки.** Реверс-прокси должен передавать `Host`, `X-Forwarded-Proto` и `X-Forwarded-For`.

## Процессор и память [#req-hw]

Прослойка лёгкая: на стенде в простое она занимала около 15 МБ памяти, под 16 одновременными запросами подписки — около 35 МБ. Больше памяти уходит на соседние контейнеры: страница подписки — около 100 МБ, MariaDB — около 90 МБ, плюс сама система и Docker.

| Вариант | Процессор | Память |
| --- | --- | --- |
| Рядом с панелью | хватит того, что есть у панели | прослойка добавит 30–60 МБ |
| Отдельный сервер, база SQLite | 1 ядро | от 512 МБ, удобнее 1 ГБ |
| Отдельный сервер, база MariaDB | 1 ядро | 1 ГБ |
| Тысячи активных пользователей | 2 ядра | 2 ГБ |
| Хостинг без Docker | обычный тариф с PHP | — |

Одно ядро обрабатывает десятки запросов подписки в секунду.

## Сервер для Docker [#req-docker]

| | |
| --- | --- |
| **Система** | Любой Linux с Docker Engine и плагином Docker Compose. Скрипт установки поставит Docker сам, если его нет. |
| **Диск** | Образ прослойки — около 600 МБ. На отдельном сервере добавляются страница подписки Remnawave (~280 МБ), по желанию MariaDB (~330 МБ), Caddy (~70 МБ) или nginx с certbot (~170 МБ). Журналы контейнеров ограничены 60 МБ на каждый. |
| **Порты** | Рядом с панелью или за своим реверс-прокси — свободный порт `8080` на `127.0.0.1`, наружу он не открывается. С Caddy или nginx из compose — свободные и открытые извне `80` и `443`. |

## Хостинг без Docker [#req-hosting]

* **PHP 8.1 или новее.**
* **Веб-сервер:** Apache с включённым `.htaccess` (mod_rewrite) или nginx с правилами из раздела [«Файлами на хостинг»](/ru/docs/install/files).
* **Папка `data/`** должна быть доступна PHP на запись: там хранятся база SQLite и настройки.
* **Сертификат HTTPS** на домене.

Расширения PHP. Мастер установки сам покажет, каких не хватает:

| Расширение | Для чего | Без него |
| --- | --- | --- |
| `curl` | связь с панелью | установка не пойдёт |
| `mbstring` | работа с текстом | установка не пойдёт |
| `pdo_sqlite` | база SQLite | нужен, если база SQLite |
| `pdo_mysql` | база MySQL / MariaDB | нужен, если база MySQL |
| `dom` | страница подписки в браузере | предупреждение |
| `sodium` | защищённый канал Clod Clash | предупреждение, канал не работает |

## База данных [#req-db]

**SQLite** стоит по умолчанию: это файл в `data/`, ничего ставить не нужно. Её хватает примерно до 1–2 тысяч пользователей. **MySQL или MariaDB** нужны, если подписки обновляются очень часто и одновременно. Для Docker есть готовые файлы compose с MariaDB. Сменить базу можно и потом, на вкладке «База данных» в админке.
