## Вебхук в панели [#after-webhook]

Если не добавили вебхук в мастере, сделайте это сейчас: строки для `.env` панели есть на вкладке «Вебхуки». Адрес вебхука — `https://sub.example.com/webhook.php`. После правки `.env` перезапустите панель.

## Домен подписки в панели [#after-domain]

* **Вместо текущей подписки.** В `.env` панели `SUB_PUBLIC_DOMAIN` — домен прослойки, без `/api/sub`. Обычно он там уже стоит.
* **Зеркало.** Пользователям нужны ссылки на домене зеркала. Они показаны на вкладке «Пользователи».

## Проверка связи [#after-check]

Вкладка «Подключение» → «Проверка связи» повторяет проверки мастера: панель, страница подписки или домен подписки для зеркала, подписка через ваш домен.

<Shot name="after-linkcheck" alt="Подключение → Проверка связи" />

Если мастер закончился с предупреждениями, в админке висит напоминание, пока вы его не закроете.

## Вход по секретной ссылке [#after-gate]

На той же вкладке включают и выключают «Дополнительную защиту» и перевыпускают ссылку. После перевыпуска старая ссылка перестаёт работать.

<Shot name="after-gate" alt="Подключение → Вход в админку по секретной ссылке" />

Из консоли:

```bash title="Терминал"
docker compose exec submw php tools/admin-gate.php         # показать ссылку
docker compose exec submw php tools/admin-gate.php --on    # включить
docker compose exec submw php tools/admin-gate.php --new   # перевыпустить
docker compose exec submw php tools/admin-gate.php --off   # выключить
```

При установке файлами — то же самое без `docker compose exec submw`, из папки сайта: `php tools/admin-gate.php`.

## Планировщик [#after-cron]

В Docker планировщик уже работает внутри контейнера. При установке файлами его нужно [добавить в cron](/ru/docs/install/files#files-cron).
