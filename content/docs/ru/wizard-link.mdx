---
title: Ссылка мастера
description: Секретная ссылка, по которой открывается мастер установки.
---

Пока прослойка не установлена, адрес `/admin/` показывает страницу-заглушку, как и корень сайта. Мастер открывается только по ссылке с ключом. Так посторонний, наткнувшийся на свежую установку, не сможет её настроить.

## Где взять [#link-where]

В Docker контейнер печатает ссылку в журнал при первом запуске:

```bash title="Терминал"
cd /opt/remnawave-subscription-middleware
docker compose logs submw
```

```text title="Вывод"
==================================================================
submw: ссылка мастера установки (откройте по своему домену, за реверсом):
    https://<домен-подписки>/admin/?kijm36wa=d4542e707f0836cc5340e737
==================================================================
```

Замените `<домен-подписки>` своим доменом, ключ после «?» оставьте как есть. Получится, например, `https://sub.example.com/admin/?kijm36wa=d4542e707f0836cc5340e737`.

* **Скриптом:** та же ссылка — в конце вывода скрипта.
* **Файлами:** ключ лежит в `data/install.json`, подробно — в [«Файлами на хостинг»](/ru/docs/install-files#files-link).
* **Потеряли ссылку:** `docker compose exec submw php tools/admin-gate.php` напечатает её ещё раз.

## Как работает ключ [#link-how]

* Когда вы открываете ссылку, браузер запоминает ключ на год. Дальше адрес `/admin/` в этом браузере открывает мастер и без ключа в адресе. На другом устройстве откройте ссылку ещё раз.
* Ключ нужен только на время установки. Если на последнем шаге поставить галочку «Дополнительная защита», та же ссылка останется ключом для входа в админку. Без галочки после установки `/admin/` открывается обычной формой входа.

## Если открылась не та страница [#link-wrong]

**«Откройте прослойку по домену».** Прослойку открыли по IP-адресу или localhost. Откройте её по домену через реверс-прокси. Если вы и так открываете по домену, реверс-прокси не передаёт заголовок `Host`: в nginx добавьте `proxy_set_header Host $host;`.

**Страница-заглушка вместо мастера.** В ссылке нет ключа или ключ не тот. Возьмите ссылку из журнала ещё раз.

**Ошибка сертификата.** Реверс-прокси ещё не выпустил HTTPS для домена. С Caddy из compose посмотрите `docker compose logs caddy`, с nginx — `docker compose logs certbot`.
